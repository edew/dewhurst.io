This is a bash function for checking if a variable is set.

```
#!/usr/bin/env bash

set -e

# Careful: this probably will not work in shells other than bash
variable_is_set()
{
	if [[ -n "${!1+x}" ]]; then
		return 0
	else
		return 1
	fi
}

variable_is_set FOO || exit 1
variable_is_set BAR || exit 1
```
